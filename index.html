How It Works

Two simple tools that solve real problems.

🔗

Link Management

You have a long, ugly affiliate link or a complicated URL. Link Forge creates a short, clean version on your own domain — like yoursite.com/go/sale. When someone clicks it, they're instantly redirected to the original URL. You can track clicks, protect with a password, or disable the link anytime.

Before: https://shop.com/ref?id=123&utm=abc After: yoursite.com/go/sale
🧱

Shortcode Blocks

Need to add custom HTML, JavaScript, or CSS to specific pages? Instead of editing theme files, create a named block in Link Forge and paste a simple shortcode like [forge block="analytics"] anywhere — in posts, pages, or widgets. Edit the code once, and it updates everywhere.

Shortcode: [forge block="my-code"] Result: Your HTML/JS/CSS appears here

Frequently Asked Questions

How do I activate PRO?

After purchase, you'll receive a license key by email. Go to WordPress admin → Link Forge → Settings, paste the key, click Activate. Done.

Can I upgrade later?

Yes. Purchase a higher plan anytime. The new key replaces the old one immediately.

One license per site?

Yes, one license = one domain. Need more sites? Buy additional licenses.

How do links work?

You create a key (like "sale") and a target URL. The plugin creates yoursite.com/go/sale — anyone who visits it is redirected to the target. You can track clicks or protect with a password.

How do shortcodes work?

Create a block with a title and your code. Use the shortcode [forge block="title"] in any post or page. Edit the block once — it changes everywhere.

What happens when license expires?

PRO features stop. Existing links keep working. You can't create new ones beyond the free limit until renewal.

Do you offer refunds?

Yes, 14-day money-back guarantee. Email us — we'll refund, no questions asked.

Can I use custom prefixes?

Yes. Free: one global prefix (like /go/). PRO: individual prefixes per link or no prefix at all.
