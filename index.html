How It Works

Two simple tools that solve real problems.

🔗

Link Management

You have a long, ugly affiliate link or a complicated URL. Link Reactor creates a short, clean version on your own domain. When someone clicks it, they're instantly redirected. Track clicks or disable anytime — with or without a prefix.

https://shop.com/ref?id=123&utm=abc → yoursite.com/go/sale or yoursite.com/sale
🧱

Shortcode Blocks

Need custom HTML, JavaScript, or CSS on specific pages? Create a named block in Link Reactor, paste the shortcode anywhere — posts, pages, widgets. Edit once, updates everywhere. Use the editor button for quick insertion without leaving the post editor.

[reactor block="my-code"] → Your HTML/JS/CSS appears here

Frequently Asked Questions

Is Link Reactor really free?

Yes! Link Reactor is 100% free and open source. There are no premium features, no upsells, and no limitations. Create unlimited links and shortcodes without any restrictions.

How do links work?

You create a key (like "sale") and a target URL. The plugin creates yoursite.com/go/sale — anyone who visits it is redirected. Track clicks or disable anytime.

Can I remove the /go/ prefix?

Yes! You can set a custom global prefix (or none) in Settings. You can also override it for each individual link.

How do shortcodes work?

Create a block with a title and your code. Use [forge block="title"] in any post or page. Edit once — changes everywhere. Or use the editor button for one-click insertion.

Does this work with caching plugins?

Yes, Link Reactor is compatible with most caching plugins. Redirects are handled at the WordPress level before caching.

Is my data secure?

All data is stored in your WordPress database. No external services are used for redirects or tracking.
